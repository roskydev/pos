PHP + MySQL ile geliştirilen  sanal pos sistemi.

## Özellikler ✨

- **Masa Yönetimi**: Masaların gerçek zamanlı durum takibi (boş/dolu/rezerve)
- **Sipariş Yönetimi**: Hızlı sipariş oluşturma ve takibi
- **Menü Yönetimi**: Ürün ekleme, silme ve fiyat yönetimi
- **Raporlar**: Gelir, satış ve masa kullanım raporları
- **Masa Geçmişi**: Detaylı masa geçmişi ve istatistikler
- **Responsive Tasarım**: Mobil ve masaüstü uyumlu arayüz
  
- ### Gereksinimler
  
- PHP 7.4+
- MySQL 5.7+
- Web Server (Apache, Nginx, vb.)
